# Repartout - Application Spring Boot (Projet de Fin de Module)

##  Description

Repartout est une application web développée avec Spring Boot dans le cadre d’un projet de fin de module en Génie Informatique.

L’application permet la gestion complète des clients, des machines ainsi que des demandes d’interventions techniques.

---

##  Objectifs du Projet

- Mettre en pratique l’architecture JEE avec Spring Boot
- Implémenter le modèle MVC
- Gérer les entités métiers avec JPA
- Développer une interface web dynamique avec JSP
- Sécuriser l’application avec Spring Security

---

##  Technologies utilisées

- Java
- Spring Boot
- Maven
- JSP
- Spring Security
- JPA / Hibernate
- Architecture MVC

---

##  Architecture du projet

Le projet suit une architecture structurée :

- **Controllers** : gestion des requêtes HTTP
- **Services** : logique métier
- **Repositories** : accès aux données
- **Entities** : modèles métier
- **JSP** : interface utilisateur

---

##  Fonctionnalités principales

- Gestion des clients
- Gestion des machines
- Gestion des interventions
- Authentification sécurisée
- Interface web interactive
